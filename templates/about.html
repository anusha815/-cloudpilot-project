How CloudPilot works

CloudPilot connects a public GitHub repository to Render, which performs the actual cloud build and hosts the application.

  1. Enter a project name, public GitHub repository URL and branch.
  2. CloudPilot securely sends a service-creation request to the Render API.
  3. Render retrieves the source code and runs the configured build command.
  4. Render deploys the application and provides a public URL.
  5. CloudPilot stores the deployment record and displays the latest status.

Detailed build and runtime logs are available in the linked Render dashboard.
